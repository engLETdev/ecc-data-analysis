# Catálogo de indicadores a definir

Estado: aguardando perguntas analíticas, bases e definições validadas. Nenhum
indicador foi implementado nesta fundação.

Para cada indicador, preencher:

| Campo | Definição validada |
| --- | --- |
| Nome e objetivo da decisão | Pendente |
| Fonte, colunas e filtros | Pendente |
| Fórmula e unidade | Pendente |
| Numerador e denominador, quando aplicável | Pendente |
| Granularidade e agregação temporal | Pendente |
| Tratamento de nulos e denominador zero | Pendente |
| Faixas e limites de qualidade | Pendente |
| Exemplo conhecido com resultado esperado | Pendente |
| Responsável pela validação | Pendente |

O cálculo deve pertencer a um módulo testável independente da interface.
Gráficos e dashboard devem consultar os resultados validados e apresentar
unidades, filtros, período e atualização. Não inferir fórmulas a partir do nome
de uma coluna sem registrar e validar a decisão.
